# GIFF - An Advanced GIF Player

A simple GIF viewer for Windows.

## How to Install the program

1. **Go on the Releases page (https://github.com/Vladozs/GIFF/releases)**

2. **Download the version you need (GIFF.exe)**

3. Set GIFF.exe as the default program for opening GIF files.

4. Open the gif file to check that it works.


## How to Use

1. **Open GIF files directly:**
   - Right-click any GIF file
   - Select "Open with"
   - Click "Choose another app"
   - Select GIFF.exe
   - Check "Always use this app"
   - Click OK

2. **Or open from inside GIFF:**
   - Run GIFF.exe
   - Click "Open GIF" button
   - Select your GIF file

## Features
- Open GIFs by double-clicking
- Play/Pause animation
- Adjust speed (slow/fast)
- Fullscreen mode
- Free and simple

## Controls
- **Open:** File -> Open or Ctrl+O
- **Play/Pause:** Space or Play button
- **Fullscreen:** F11 or double-click
- **Exit:** Esc or Alt+F4
- **Speed:** Use the slider

## Uninstall
1. Right-click GIF files
2. Choose another app as default
3. Delete GIFF.exe
